# 怎么写日记

以前试过很多次写日记，每次都坚持不过三天。后来想通了——问题不是「有没有毅力」，是「日记的定义太重了」。总觉得日记必须是一篇完整的文章，有开头有结尾有感悟。

现在改用最简单的格式：日期 + 一句话描述当天。比如：

> 3.12 今天把 RAG 项目的混合检索模块调通了。开心。
> 3.11 又刷了一下午视频。明天开始用番茄钟。
> 3.9 读完了《Why Nations Fail》第一章，生词记了半页。

有时候用英文写，强迫自己用另一种语言组织想法。写错了也没人看。

日记不是给别人看的艺术品。它的作用只有一个：**把脑子里的东西倒出来，减轻心理负担。** 心情不好的时候写下来比憋着舒服很多。

最近在日记里写了几条规则放床头——「不抱怨」「不恐惧」「接纳一切发生」。不是写给别人看的宣言，是给自己大脑的操作指南。
