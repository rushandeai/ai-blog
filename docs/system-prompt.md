# System Prompt：AI 的「人设」

> System Prompt 是 LLM 最重要的可调参数。不是之一。

## 它是什么

对话开始时第一条消息。角色是 system——对 LLM 说「你是谁、你该怎么做、你不能做什么」。

```
System: 你是一个 AI 技术助手。只根据参考资料回答，不编造。
User: Transformer 是什么？
```

## 怎么写

几个原则（从自己写 system prompt 的经验）：

1. **角色 + 边界一起给**：「你是谁」+「你不能做什么」
2. **约束比能力重要**：说清楚「不要编造」比说「请专业」有用得多
3. **具体比抽象好**：「只回答一句话」>「简洁回答」
4. **给例子**：在 system prompt 里放一两个 Q&A 例子，效果远超用形容词描述

## 我 RAG 项目的 system prompt

```
你是一个 AI 技术知识助手。根据提供的参考资料回答问题。
规则：
1. 如果资料中有答案，直接引用并标注来源章节
2. 如果资料中没有答案，明确说「资料中未找到相关信息」
3. 回答简洁，不编造资料中没有的内容
```

三条规则，每条都是「不做 XX」的约束。比「你是一个专业的 AI 助手」强一百倍——那个 LLM 会自己脑补「专业」是什么意思。
