# 几句一直提醒自己的话

打在 Obsidian 里，偶尔翻出来看一遍。

**期待是痛苦的开始。** 不对别人报期待，用心努力去做，什么结果都坦然接受。

**我没有任何可恐惧的，我接纳一切发生。** 恐惧解决不了任何问题。接受现状，然后行动。

**创业不要从投入金钱开始。** 先投入自己的劳动力，当自己 cover 不住时再投入金钱扩大。这个原则也适用于学习——先投入时间自己搞懂，不行再花钱报课。

**不抱怨。** 任何时候，对任何人，关于任何事。想解决就去做，不想解决就闭嘴。抱怨不产生解决方案，不改善情绪，还把周围人推远。没有人喜欢经常抱怨的人。

**学习和赚钱是同一条路。** 能力 × 认知 × 行动 = 收入。任何一维塌了，钱就上不去。这条对转行尤其重要——不能只学，得做项目；不能只做，得想清楚方向。

**急是最大的敌人。** 焦虑和自责是效率杀手，比拖延更可怕。不和别人比，只和昨天的自己比。但「不焦虑」不等于「不行动」。

就这些。不多，每条都是自己踩过坑才写上去的。
