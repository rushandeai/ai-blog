# Few-shot 和 Chain-of-Thought：两个最简单的提示技巧

> 不玄学。就是「给例子」和「让 AI 一步步想」。

## Few-shot：给例子

```
❌ 「把这句话翻译成英文：今天天气很好」
✅ 「把中文翻译成英文：
    你好 → Hello
    谢谢 → Thank you
    今天天气很好 →」
```

给两个例子（你好→Hello，谢谢→Thank you），AI 理解了你想要什么格式、什么风格、什么长度。比写一长串要求高效得多。

2-3 个例子是最佳数量。1 个太少（AI 可能过度模仿那个例子的具体内容），5 个以上边际收益递减。

## Chain-of-Thought：让 AI 一步步想

```
❌ 「357 × 468 = ?」
✅ 「357 × 468 = ? 请一步步计算。」
```

AI 在「一步步写过程」的时候，推理更准确。因为每步的输出都变成下一步的输入——错误不会跨步传播。

对数学、逻辑、代码调试有效。对简单翻译、闲聊没用。

## 两个技巧结合

Few-shot + CoT = 给一个「一步步思考」的例子：

```
Q: 这个 Bug 怎么修？
A: 让我一步步分析。
    1. 先看错误日志：AttributeError: 'NoneType' object has no attribute 'name'
    2. 这说明 user 对象是 None
    3. 检查 user 在哪赋值的：第 15 行 user = get_user(id)
    4. get_user 可能返回 None
    5. 建议加 if user is None 判断

Q: 这个接口为什么慢？
A: 让我一步步分析。
```

AI 学会的不只是「要一步步分析」，还学会了这种具体的分析格式。
