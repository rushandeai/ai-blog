# 关于冥想

开始冥想是因为刷短视频的失控感——手不知不觉摸到手机，回过神来半小时没了，然后极度自我厌恶。

后来了解到前额叶皮质可以训练。冥想是最直接的方式——哈佛的研究，8 周冥想，MRI 可见前额叶灰质密度增加。

我现在的做法：每天 20 分钟。坐下来，关注呼吸。脑子里冒出「看一下手机」「今天好像有个什么事」，注意到这个念头，拉回来，继续关注呼吸。拉回来多少次不是重点——**拉回来这个动作本身就是训练**。

刚开始觉得 20 分钟是浪费。坚持一周后发现不对——不是浪费，是对手机的冲动明显弱了。以前拿起手机的间隔大概 20 分钟，冥想之后能专注 40 分钟以上。20 分钟冥想换来一天的专注提升，很值。

配合有氧运动效果更好。跑半小时回来脑子特别清醒。冥想 + 有氧 + 睡够——这三件事对专注力的影响比任何生产力技巧都大。

不是玄学。试一周自己判断。
